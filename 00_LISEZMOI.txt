DÉPLOIEMENT
===========

LOCAL:
  Windows: run.bat
  OU: pip install -r requirements.txt && streamlit run app.py
  Accès: http://localhost:8501

STREAMLIT CLOUD (GRATUIT):
  1. Créer repository GitHub
  2. Aller sur share.streamlit.io
  3. Déployer depuis GitHub
  4. URL: https://user-app.streamlit.app

SERVEUR PERSONNEL:
  streamlit run app.py --server.port 8080 --server.address 0.0.0.0
  Accès: http://serveur:8080

DOCKER:
  docker build -t streamlit-eau-togo .
  docker run -p 8080:8080 streamlit-eau-togo
  Accès: http://localhost:8080
